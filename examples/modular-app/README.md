# Clinic appointments (fictional example)

Fictional modular application (NestJS-style API + Next.js web) used to show
Archflow's hierarchical map, functional dependencies (guards, RBAC policies,
DTOs, enums, contracts, events) and process documentation. There is no source
code behind it; code references point to paths that do not exist.

```bash
archflow serve --repo examples/modular-app
```
